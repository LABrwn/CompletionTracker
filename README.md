# Completion Tracker (Sammel-Tracker)

Fabric-Mod für Minecraft 26.3. Verfolgt, welche Mobs du getötet, welche Items du gesammelt und welche Fortschritte du erreicht hast, mit Hinweisen zu allem, was noch fehlt.

## Installation

1. [Fabric Loader](https://fabricmc.net/use/) für Minecraft 26.3 und die [Fabric API](https://modrinth.com/mod/fabric-api) installieren.
2. Unter **Releases → Neueste Version** die Datei `completiontracker-….jar` herunterladen.
3. Die Datei in den `mods`-Ordner ziehen.
4. Im Spiel **J** drücken.

## Entwicklung

Jeder Push wird von GitHub Actions gebaut (`.github/workflows/build.yml`). Auf `main` landet die fertige .jar automatisch im Release „Neueste Version“.
